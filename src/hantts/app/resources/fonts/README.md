# 글꼴 (직접 내려받아 이 폴더에 넣기)

| 글꼴 | 파일 | 라이선스 | 받는 곳 |
|---|---|---|---|
| IBM Plex Sans KR | `IBMPlexSansKR-Regular.ttf`, `-Medium`, `-SemiBold`, `-Bold` | SIL OFL 1.1 | https://github.com/IBM/plex (또는 Google Fonts) |
| JetBrains Mono | `JetBrainsMono-Medium.ttf` | SIL OFL 1.1 | https://github.com/JetBrains/JetBrainsMono |

- 각 글꼴의 `OFL.txt`를 함께 넣고, 설정 > 정보 > 오픈소스 라이선스에 표시한다.
- 파일이 없으면 `theme.apply()`가 "맑은 고딕"으로 대체한다.
