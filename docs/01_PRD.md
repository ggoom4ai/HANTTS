# 01. 제품 요구사항 (PRD)

## 1. 목표
GPU 없는 일반 Windows PC에서 설치 한 번으로 고품질 한국어 음성을 만드는 데스크톱 TTS 스튜디오.
여러 오픈소스 엔진을 하나의 일관된 UI로 묶고, 각 엔진 고유 기능은 숨기지 않고 모두 노출한다.

## 2. 대상 사용자
- 유튜브/강의 영상 내레이션 제작자, 오디오북·접근성 자료 제작자 (비개발자)

## 3. 기능 요구사항

### F1. 엔진 선택 및 관리
- F1.1 지원 엔진: Supertonic 3, MeloTTS, Windows 음성(OneCore/SAPI 5 내장 TTS). Kokoro·Piper·Soprano는 한국어 미지원으로 제외
- F1.2 엔진 미설치 시 "설치" 버튼 → 앱이 직접 다운로드·설치 (Python 환경 + 패키지 + 모델 가중치)
- F1.2a Windows 음성: 다운로드 없음. 한국어 음성이 없으면 [Windows 설정에서 설치] 또는 [자동 설치(관리자 승인)]로 Windows 한국어 음성 팩 설치
- F1.3 설치 진행률(단계/바이트/ETA), 일시정지·취소·재시도, 실패 시 "복구" 기능
- F1.4 엔진 제거, 업데이트 확인, 디스크 사용량 표시
- F1.5 오프라인 엔진 팩(`.htpack`) 가져오기 — 인터넷 없는 PC 지원
- F1.6 프록시 / Hugging Face 미러 주소 설정
- F1.7 각 엔진 카드에 **한국어 지원 등급 배지**(공식 / 실험적 / 미지원)와 라이선스 표시

### F2. 합성
- F2.1 텍스트 입력(편집기), 파일 열기(.txt, .md, .docx, .srt)
- F2.2 엔진·언어·음성(화자) 선택
- F2.3 엔진별 모든 파라미터를 **Capability Schema 기반 동적 패널**로 노출 (기본/고급 탭)
- F2.4 미리듣기(선택 영역 / 현재 문장), 전체 합성, 중지
- F2.5 긴 텍스트 자동 분할 → 문장 단위 진행률 → 병합, 문장 사이 무음 길이 조절
- F2.6 문장 단위 점진 재생: 첫 문장이 생성되면 바로 재생을 시작하고 나머지는 이어서 생성
- F2.7 출력: WAV / MP3 / FLAC / OGG, 샘플레이트 변환, 음량 정규화(LUFS)
- F2.8 자막(SRT) 동시 생성 (문장 단위 타임스탬프; Windows 음성처럼 단어 경계를 주는 엔진은 단어 단위)
- F2.9 SSML 모드(Windows 음성): 원고를 SSML로 해석해 쉼·강조·발음을 태그로 지정

### F3. 한국어 텍스트 처리 (→ 07_TEXT_FRONTEND.md)
- F3.1 숫자·날짜·시간·단위·기호 한국어 읽기 변환 (토글)
- F3.2 사용자 발음 사전 (단어 → 읽기), 엔진별/전역 적용
- F3.3 영문 약어 읽기 규칙 (예: "AI" → "에이아이") 선택 적용
- F3.4 변환 결과 미리보기 ("엔진에 실제로 들어갈 텍스트")

### F4. 생산성
- F4.3 프리셋 저장/불러오기 (엔진+음성+파라미터)
- F4.4 히스토리: 생성 기록 목록, 재생, 선택삭제, 전체 삭제(확인 후). 목록에서만 지우고 이미 저장된 음성 파일은 남긴다
- F4.5 문단별 음성 지정(대화체): 줄 앞 태그 `[F1] 안녕하세요` 형식으로 화자 전환 (선택 기능)

### F5. 앱 공통
- F5.1 한국어 UI 기본, 영어 UI 선택
- F5.2 라이트/다크 테마, 글꼴 크기 조절, 키보드 단축키
- F5.3 첫 실행 마법사: 기본 선택은 Windows 음성(설치 없이 바로 읽기). Supertonic 3·MeloTTS는 용도를 고를 때만 설치한다
- F5.4 CLI 제공(`hantts-cli`) — 같은 엔진 계층을 사용 (자동화·배치용)
- F5.5 로그 보기 / 진단 정보 내보내기(zip)

> 요청서의 "사용자 친화적인 CUI"는 GUI의 오타로 해석했다. 별도로 F5.4 CLI를 함께 제공하므로 두 해석 모두 충족한다.

## 4. 비기능 요구사항
| 항목 | 목표 |
|---|---|
| OS | Windows 10 22H2 / Windows 11, x64 (ARM64는 범위 외) |
| 하드웨어 | 4코어 CPU, RAM 8GB에서 Supertonic 3 / MeloTTS 실시간 이상 |
| 설치 파일 | 앱 본체 인스톨러 ≤ 150MB (엔진·모델은 별도 다운로드) |
| 관리자 권한 | 불필요 (사용자 단위 설치 기본. 관리자 설치는 마법사에서 고를 수 있다) |
| 설치 위치 | 대상 폴더 페이지에서 사용자가 고른다. 기본은 `%LOCALAPPDATA%\Programs\HanTTS`. 설정과 기록은 설치 폴더와 따로 `%LOCALAPPDATA%\HanTTS` |
| 앱 시작 | 2초 이내 창 표시 (엔진 로딩은 백그라운드) |
| 응답성 | 합성 중에도 UI 멈춤 없음 (모든 엔진 작업은 별도 프로세스) |
| 안정성 | 엔진 크래시가 앱을 죽이지 않음, 워커 자동 재시작 |
| 개인정보 | 텍스트는 외부로 전송하지 않음. 네트워크는 엔진/모델 다운로드와 업데이트 확인에만 사용 |
| 재현성 | 모든 다운로드는 버전 고정 + SHA256 검증 |
