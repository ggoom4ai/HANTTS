# 05. UI 명세

> 비주얼(색·글꼴·크기)과 Qt 구현 방법은 **[12_UI_DESIGN.md](12_UI_DESIGN.md)** 와 `design/mockups/` 를 따른다. 아래 ASCII 와이어프레임은 기능 배치 참고용이다.

## 1. UX 원칙
- **기본은 단순, 고급은 한 번 더 클릭** — 파라미터 패널은 `기본` / `고급` 탭. 처음 사용자는 엔진·음성·속도만 보인다.
- **엔진 상태를 항상 보이게** — 상단 엔진 선택기에 상태 점(● 설치됨 / ○ 미설치 / ◐ 설치 중 / ✕ 오류).
- **막히는 순간에 해결책을 제시** — 미설치 엔진을 고르면 그 자리에서 설치로 안내하고, 한국어 Windows 음성이 없으면 음성 팩 설치를 안내한다.
- **비동기·취소 가능** — 모든 긴 작업은 진행률 + 취소 버튼. UI 스레드는 절대 블로킹 금지.
- 문구는 쉬운 한국어, 기술 용어는 툴팁에서 설명 (예: "noise_scale" → 라벨 "음색 변화", 툴팁 "값이 클수록 매번 조금씩 다른 음색").

- 엔진 미설치 시 오른쪽 패널 대신 **설치 카드**: 엔진 설명, 한국어 등급 배지, 용량, 라이선스, [설치] 버튼.
- Windows 음성 선택 + 한국어 음성 없음: 편집기 상단 배너 "이 PC에 한국어 Windows 음성이 없습니다." 엔진 카드에서 [Windows 설정에서 설치] [자동 설치].
- 편집기 기능: 줄 앞 `[음성ID]` 태그 자동완성, Windows 음성의 SSML 모드에서는 `<break>`, `<emphasis>`, `<prosody>`, `<sub alias>` 태그 자동완성·하이라이트.
- 문장 클릭 → 그 문장만 재생/재생성 (청크 단위 캐시).

## 4. 동적 파라미터 패널 규칙 (`app/param_panel.py`)
Capability Schema(06 문서)의 `ParamSpec` → 위젯 매핑:

| `type` | 위젯 | 비고 |
|---|---|---|
| `float` / `int` (min,max 있음) | 슬라이더 + 스핀박스 | `step`, `unit` 표시 |
| `int`/`float` (범위 없음) | 스핀박스 | |
| `bool` | 토글 스위치 | |
| `enum` | 콤보박스 (항목 ≤ 6이면 세그먼트 버튼) | `choices[].label_ko` |
| `string` | 한 줄 입력 | `regex` 검증 |
| `file` | 경로 + [찾아보기] | `file_filter` |
| `voice_blend` | 음성 + 가중치 행 추가/삭제 리스트 | (v1 엔진에는 없음, 구조만 유지) |

- `group`(기본/고급), `order`, `visible_if`(예: `{"streaming": true}`)로 배치·표시 제어
- 각 위젯 옆 ↺(기본값), 라벨 옆 ⓘ 툴팁(`help_ko`)
- 값 변경은 ViewModel에만 반영, 합성 시 `params` dict로 전송. 엔진 전환 시 엔진별 마지막 값 기억.

## 6. S5 발음 사전
표: 원문 | 읽기 | 적용 범위(전역/엔진별) | 대소문자 구분 | 정규식 여부 | [▶ 들어보기]. CSV 가져오기/내보내기.

## 6.1 S6 기록
행 목록(시각 · 엔진 · 길이 · 원고 앞부분). [재생] [선택삭제] [전체 삭제]. 선택삭제는 고른 행만, 전체 삭제는 확인 후 기록 전부를 지운다. 이미 저장된 음성 파일은 남긴다. 여러 행은 Ctrl·Shift로 고른다.

## 7. S7 설정
일반(언어, 테마, 글꼴 크기, 시작 시 마지막 엔진 미리 로드) · 성능(CPU 스레드 수 기본=min(4, 물리코어-1), 동시 워커 상한, 유휴 종료 시간 기본 2분) · 저장(엔진 폴더, 출력 폴더, 임시 파일 정리) · 네트워크(프록시, HF 미러, 업데이트 확인) · 오디오(출력 장치, 기본 형식, LUFS 목표 -16) · 고급(로그 수준, 진단 정보 내보내기). 엔진 폴더는 저장 즉시 적용되고, 그 폴더의 가상환경·모델을 설치와 합성에 쓴다.

## 8. 단축키
F5 미리듣기 · Ctrl+Enter 전체 생성 · Esc 중지 · Space 재생/일시정지(편집기 밖) · Ctrl+S 오디오 저장 · Ctrl+O 열기 · Ctrl+1~5 엔진 전환 · Ctrl+, 설정.

## 9. 접근성 / 국제화
- 모든 위젯 `accessibleName` 지정(스크린리더), 고대비 테마, 키보드만으로 전 기능 사용
- 문자열은 `self.tr()` + Qt Linguist(`.ts`) — `ko_KR` 기본, `en_US`
- 한국어 글꼴: 시스템 "맑은 고딕" 기본, 편집기 글꼴 변경 가능
